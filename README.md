# Extraction-DOC

Documentation site source for **Extraction Loop & Stash Kit — Stash, Raid, Insurance & Traders for Unity** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/Extraction-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, The Home Window, One-Click Setup, The Stash, Raid State Machine, Settlement, Insurance, Traders & Economy, Persistent Saving, Integration API, Transport Hooks, Reference Raid — Greyline Depot, Economy Config, What v1 Is Not, FAQ, Troubleshooting, Changelog, Support
- No `assets/` media in this tree: the pages are written so they do not depend on any image (the MergeGuard-DOC precedent). Screenshots join the tree only from real Editor captures — documentation never ships invented imagery.

Extraction Loop & Stash Kit itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.
