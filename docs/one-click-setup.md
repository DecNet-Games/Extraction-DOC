# One-Click Setup
{: .no_toc }

Setup runs from the **Welcome** section of the [Home window]({{ site.baseurl }}/docs/home-window/).

## What setup does

- Prepares the kit's install state in your project: the demo profile, the sample economy data (including the Depot Trader), and the save document's home.
- Verifies the install and reports the result in the status strip and the setup report.

## The honesty rule

Setup **reports in plain language** — including, honestly, when the optional multiplayer demo dependency is absent and the kit is running in its **solo configuration**. You will see the product's own line: "Multiplayer demo unavailable: NGO is not installed."

That line is the product working as designed, not an error: **v1 is a solo loop with transport hooks**, and the window says so rather than implying a multiplayer mode exists. See [Transport Hooks]({{ site.baseurl }}/docs/transport-hooks/) and [What v1 Is Not]({{ site.baseurl }}/docs/what-v1-is-not/).

Setup is **safe to re-run**: verifying a healthy install is its normal second-run outcome.
