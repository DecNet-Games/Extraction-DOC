# Support

## Email

**support@decnetgames.com** — the support address for Extraction Loop & Stash Kit and every Decnet Games product. When you write about a settlement or a raid, include the itemized record: the settlement lines (kept / lost / insured-pending / sold / fees) and any rejected-transition log line — those make a report answerable instead of speculative.

## Before you write

- [Troubleshooting]({{ site.baseurl }}/docs/troubleshooting/) covers the states the kit reports about itself: placement rejections, rejected transitions, the solo-configuration line, and backup recovery.
- [What v1 Is Not]({{ site.baseurl }}/docs/what-v1-is-not/) is the boundary list — if the thing you need is on it (multiplayer, a verified adapter for a specific third-party controller, a character controller), it is a v1 boundary, not a bug.
