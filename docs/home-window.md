# The Home Window
{: .no_toc }

**Tools → Decnet Games → Extraction Loop & Stash Kit** opens the Home window. Everything the kit does in the Editor lives in this one window.

## Status strip

The strip at the top reads **real install, save and demo state** — what is installed, what your save document holds, and how the demo is configured. State is reported honestly, in plain language: when the optional multiplayer demo dependency is absent, the window says the kit is running in its **solo configuration** (you will see the product's own line, "Multiplayer demo unavailable: NGO is not installed"). Solo is v1's configuration — see [Transport Hooks]({{ site.baseurl }}/docs/transport-hooks/).

## Welcome

One-click setup and verification. See [One-Click Setup]({{ site.baseurl }}/docs/one-click-setup/).

## Stash Board preview

A live preview of your demo profile's stash — the shaped-item grid your players will manage. See [The Stash]({{ site.baseurl }}/docs/the-stash/).

## Raid Loop

Your last raid's summary, read from the raid state machine: where the raid went, and how it settled. See [Raid State Machine]({{ site.baseurl }}/docs/raid-state-machine/) and [Settlement]({{ site.baseurl }}/docs/settlement/).

## Traders & Insurance

The trader surface plus the **pending-returns list** — insured items scheduled to come back, visible until they land. See [Traders & Economy]({{ site.baseurl }}/docs/traders-and-economy/) and [Insurance]({{ site.baseurl }}/docs/insurance/).

## Samples & Scenes
